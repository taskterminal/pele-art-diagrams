Diagrams, drawn by hand

Four made-up worlds, one diagram each. pele lays every diagram out, and JavaScript draws it, stroke by stroke, with a simulated pen and coloured pencils. Nothing here is an image file: each picture is drawn in your browser as you read.

The four plates

How they were made

  1. Write the diagram as text. A few lines of Mermaid.
  2. Let pele lay it out. pele, Obsidian's open-source Mermaid renderer, places every box, band, curve and label. It measures each word with the same hand lettering the drawing uses, so everything fits.
  3. Draw it by hand, in code. A program reads pele's shapes back and redraws them with a simulated fine pen and coloured pencils, then draws the world around them. Every letter is traced from A. V. Hershey's 1967 engraving letters. The program runs right here, in your browser.
